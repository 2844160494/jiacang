# 剪藏 · 全局剪贴板 2.2

一个只在本机工作的 Android 剪贴板整理器：**不打开 DSH，也能在后台收下你在任何应用里复制 / 剪切的内容**，自动识别分类、抽出最值得一键复制的那个值，再用一个更安静的界面把它们排好。

- 安装包：[GitHub Releases](https://github.com/2844160494/jiacang/releases/latest)（固定签名，Android 10+，可直接覆盖安装 2.0/2.1）
- 源码：[GitHub 仓库](https://github.com/2844160494/jiacang)
- 应用名仍是「全局剪贴板」，界面品牌叫「剪藏」；包名保持 `dev.local.globalclip`，旧历史会在首次启动时自动迁进新数据库。
- 2.2 针对 Android 17 / ColorOS 17 修了启动闪退：换回系统主题、纯 PNG 图标，并停止在打开 App 时自动拉起捕获服务；第一次打开先手动点「已暂停」开启记录。

## 这次改了什么

### 说明：2.2 的启动修复

2.0 在 ColorOS 17 上打开即退。2.2 去掉了启动时自动拉起前台服务、换回系统原生主题和 PNG 图标，并加了错误兜底页。第一次打开应用会显示「已暂停」，点一下状态胶囊允许悬浮窗/通知后才会启动捕获服务；之后服务会常驻，开机也会按设置恢复。

- 暖纸色 + 墨绿 + 珊瑚点缀的极简主题，衬线标题、卡片式列表、无边框大留白。
- 顶部是「今日 / 本周 / 置顶」概览和分类分布，下面才是搜索与分类标签；没有数据时自动收起这些区块，只留下插画和「读取当前剪贴板」。
- 卡片只保留一个最有用的动作：验证码是「复制验证码」，链接是「打开」，电话是「拨号」，邮箱是「写邮件」，地址是「地图」，其余是「复制」。
- 点卡片打开底部详情：识别结果、可选中原文、复制全文、置顶、分享、删除；删除后底部出现「撤销」。
- 设置也收进了底部弹层：记录开关、3/5/10/30 秒检查间隔、悬浮窗/通知/电池/无障碍权限、DSH 同步、清理历史。原来的六个大灰按钮不再占主屏。
- 应用图标、通知小图标、启动页也都换成了「夹着珊瑚星标的纸夹」。
- 窄到 260dp 左右的小窗也能用：标签横向滚动、文字自动省略、弹层高度按当前窗口限制。

### 自动分类

识别器是纯本地规则，不联网、不调用模型，几十微秒完成。当前有 12 类：

| 分类 | 识别方式 | 卡片上抽出的值 |
|---|---|---|
| 验证码 | 「验证码 / OTP / code」上下文里的 4–8 位码，或单独的 6 位数字 | 码本身 |
| 链接 | http(s)/ftp、www、常见域名 | 规范化后的 URL |
| 联系方式 | 邮箱、手机号、400/800、座机 | 邮箱或号码 |
| 账号密钥 | 账号/密码/用户名/token/私钥等键值；GitHub、OpenAI、Slack、AWS 令牌 | — |
| 代码 | 花括号、分号、JSON、SQL、HTML、常见语言关键字，并判断语言与行数 | — |
| 命令 | 首行是 git/npm/adb/docker/curl… 或带 `&&`、`|` 的终端命令 | — |
| 路径 | `/sdcard/...`、`~/`、`C:\...`、带扩展名的文件名，甚至中文句子里夹着的路径 | 路径本身 / 文件名 |
| 金额 | ¥/$/€ 金额、带「元」的数字、价格/金额上下文 | 金额 |
| 地址 | 省市区 + 路/街/号/小区/大厦等组合 | 原文 |
| 号码 | 身份证、银行卡、快递单号、订单号、4–8 位数字 | 号码 |
| 长文 | 45 字以上或两行以上 | 首句 |
| 短句 | 兜底 | 首行 |

分类会跟着内容走：同一段内容重复复制只保留一张卡，次数 +1、时间刷新到最前；置顶的永远在最上面；搜索同时匹配原文、标题、识别结果、分类名和「复制 / 剪切」来源。设置里还留了一个「读取当前剪贴板」，没开后台记录时也能手动收一条。

### 复制 / 剪切

Android 的剪贴板 API 不告诉你这次是复制还是剪切。2.x 加了一个**可选**的「剪切识别」：

- 在系统无障碍里启用「剪藏 · 剪切识别」后，它只旁听编辑框的「选区变化 + 文本变化」；
- 如果用户先选中一段文字、随后这段文字被整段删除（没有同时插入字），就判断很像剪切；
- 剪藏会立刻弹一次 1×1 悬浮窗读剪贴板，读到同样内容就把这条标成「剪切」，否则是「复制」；
- 删掉的文字只在内存里留 9 秒；不读通知、不读聊天内容、不联网、不落盘保存；关掉开关就停止。

默认关闭。不开也不影响正常记录，只是所有条目显示「复制」。它只能算启发式：在输入法联想、整段替换、跨应用拖拽等场景里可能漏判或误判。

## 为什么后台要一个 1×1 的悬浮窗

Android 10 起，系统只允许**当前有窗口焦点的应用**、**默认输入法**或持有 `READ_CLIPBOARD_IN_BACKGROUND` 的特权应用读剪贴板；这个限制同时盖住 `getPrimaryClip()`、`getPrimaryClipDescription()` 和变更回调。普通应用没有「安静监听」这条路。

所以后台检查时，剪藏会弹一个 1×1、透明度 0.01 的可聚焦悬浮窗，拿到焦点后读一次，200ms 内移除并把焦点还回去。这是 UniClipboard 一类工具的定时轮询做法。自己的界面在前台时直接读，不弹窗。

代价是每轮检查可能让输入法闪一下；默认 5 秒，可在设置里改成 10 秒或 30 秒。没有悬浮窗权限时，只能在前台手动读。

## 安装

1. 把 `dist/jiacang-2.2.apk` 传到手机，点开安装（允许「安装未知来源应用」）。
2. 打开「剪藏」：
   - 点顶部「已暂停」或空状态的「开启后台记录」；
   - 先允许**悬浮窗**（必须），再允许**通知**（Android 13+）；
   - 国产 ROM 建议把电池设为「无限制」，并在最近任务里加锁。
3. 去任意应用复制一段文字，回到剪藏，几秒内应该出现一张自动分好类的卡片。
4. 想区分剪切：设置 → 剪切识别 → 打开开关 → 在系统无障碍列表启用「剪藏 · 剪切识别」。

如果覆盖安装失败（签名不一致），说明旧版不是用同一个 debug key 打的；先卸载旧版再装（旧数据会丢，介意的话先在旧版里手动复制需要的内容）。

## 自己构建

### 方式 A：GitHub Actions

把 `global-clip/` 推到 GitHub 仓库 → Actions → `build-jiacang` → Run workflow → 下载 `jiacang-debug-apk`。

### 方式 B：Android Studio / Gradle

`File → Open` 选 `global-clip/`，等 Gradle 同步，`Build → Build APK(s)`。或命令行：

```sh
gradle assembleDebug
```

需要 JDK 17、Gradle 8.7+，`app/build.gradle.kts` 里 `compileSdk = 34`、`minSdk = 29`、`versionCode = 4`。

### 方式 C：本机手动打包（不依赖 Gradle）

本机（aarch64 Android 用户态）已经准备好了 JDK 17、android.jar、aarch64 版 aapt2、d8、apksigner：

```sh
./build.sh
# 产物：dist/jiacang-2.2.apk
```

脚本支持用环境变量覆盖工具路径：`JDK`、`ANDROID_JAR`、`AAPT2`、`AAPT2_LIBS`、`D8_JAR`、`APKSIGNER_JAR`、`KEYSTORE`。它会用一个临时 manifest 补上 aapt2 手工 link 需要的 `package` 属性，再把 `AndroidManifest.xml` 和 `resources.arsc` 压成 4 字节对齐，最后签名。`scripts/align_apk.py` 只做这件事。

## 数据与隐私

- 历史存在应用私有 SQLite：`clips-v2.db`，最多 2000 条，单条最多 12000 字符；置顶不会被自动裁掉。
- 旧版 SharedPreferences 里的 `clips` 会在首次启动时迁移，迁移成功后打标记，不会重复导入。
- Android 13+ 标记为敏感的剪贴板内容（密码框等）直接跳过。
- DSH 同步默认关闭，需要时在设置里手动打开；打开后只连 `http://127.0.0.1:3080`，没有账号、没有统计、没有崩溃上报。
- 崩溃时会尽量在系统「下载」目录写一份 `jiacang-crash.txt`（只有堆栈，不含剪贴板内容），方便排查；不崩溃就不会写。
- 应用 `allowBackup=false`，卸载即清空。

## 已知边界

- 后台每轮检查会短暂抢焦点，**可能让输入法收起/闪一下**，尤其快速打字时；把间隔调大能缓解。这是 Android 10+ 的硬限制。
- Android 12+ 首次读取某段内容时，系统可能弹「剪藏已读取剪贴板」提示；同一内容只提示一次。
- 剪切的判断是启发式，做不到 100%；输入法联想、整段替换、跨应用拖拽都可能干扰。
- 部分 ROM 会限制悬浮窗/后台启动，权限给全也可能被杀；建议常驻通知 + 电池白名单 + 最近任务加锁。
- 需要无障碍权限的剪切识别在部分 ROM 上会被系统定期关闭，需要重新打开。
- 安装包使用本地固定签名（`keys/debug.keystore`，已 gitignore），适合自用和小范围分发；要更正式的发布可以换成独立的 release key。源码以 MIT 许可证开放。
- 没有实现 Shizuku 特权读取；想完全免抢焦点可以后续加，但需要设备安装并启动 Shizuku。
